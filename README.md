# Bleach-like (codename REISHI)

A non-commercial **Bleach fan game**: a third-person action brawler in highly detailed voxel art, built with
**Three.js**, where the whole world is destructible and every character can do everything they do in the
manga/anime. Balance is not a goal — overpowered characters stay overpowered.

**Status:** planning. Read [`PLAN.md`](PLAN.md) for the full plan (architecture, destruction engine, combat,
roster, maps, milestones).

Research behind the plan:
- [`docs/roster/`](docs/roster/) — character dossiers (appearance & palettes, forms, complete ability lists,
  kit proposals, AI notes), summarised from the Bleach Wiki.
- [`docs/lore/mechanics.md`](docs/lore/mechanics.md) — Kidō catalogue, racial techniques, power rules.
- [`docs/lore/locations.md`](docs/lore/locations.md) — locations and map generator specs.
- [`docs/research/lookdev/`](docs/research/lookdev/) — rendering experiments (voxel scale, AO, post-processing).
- [`tools/wiki/wiki_fetch.py`](tools/wiki/wiki_fetch.py) — Bleach Wiki fetcher (MediaWiki API).
